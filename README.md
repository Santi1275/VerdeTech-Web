# VerdeTech: Tu Oasis Inteligente

Creá una página web tipo Elevator Pitch de una sola página para EXPO ITES 2026, sobre VerdeTech. Debe ser moderna, visual y responsive para celular y computadora, pensada para entender el proyecto en menos de 5 minutos. Entregar todo en un único archivo index.html con HTML, CSS y JavaScript embebidos. Usar español rioplatense claro. Incluir: nombre VerdeTech; logo/icono temporal fácil de reemplazar; frase principal basada en un terrario/caja de madera inteligente que cuida plantas usando sensores y actuadores; problema: falta de tiempo para cuidar plantas; solución: planta que se cuida sola; propuesta de valor: no perder una planta por falta de prioridad; público objetivo: todas las edades; funcionamiento: mide temperatura y humedad, enciende coolers si hace calor y los apaga si hace frío; riega cuando la humedad es baja y no actúa si es suficiente; prototipo con placeholders claramente marcados para subir imágenes después; modelo de negocio inventado de forma realista; integrantes Matteo Gauthier y Santiago Caloia; futuro: cambiar pantalla temporal pequeña por la planeada y usar microcontrolador más potente por RAM limitada; CTA creativa. Donde falten datos, indicá claramente qué debe completar el equipo. Incorporar navegación por secciones, animaciones sutiles y diseño verde/natural con estética tecnológica.
